# Datos históricos

Este directorio separa el contenido histórico de la programación.

Regla editorial: fuente → investigación → verificación → adaptación para primaria → publicación.

Estados: investigando, documentado, verificado, adaptado, publicado.

No se publica una afirmación histórica sin fuente identificable. Los relatos orales se incorporarán como testimonios, diferenciados de hechos documentales.
