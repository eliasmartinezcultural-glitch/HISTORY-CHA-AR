# Sistema de diseño · V0.2

## Idea rectora
El producto debe sentirse como un cuaderno de exploración del territorio: documental, cálido, contemporáneo y aventurero. Nunca como una enciclopedia ni como un juego infantil.

## Jerarquía
1. Mirar
2. Elegir
3. Descubrir
4. Comprender
5. Volver

## Lenguaje visual
- Tierra, agua, cielo y papel como familias cromáticas.
- Grandes formas territoriales antes que decoración.
- Tipografía de alta legibilidad y títulos con personalidad.
- Tarjetas con profundidad física suave.
- Movimiento breve y funcional: entrada, selección y transición.
- Nada debe competir con el contenido.

## Componentes
- Shell: marco principal de la experiencia.
- Topbar: identidad + orientación.
- Progress: indica dónde está el niño sin sobrecargar.
- Timeline: eje vertical/curvo de acontecimientos.
- Event card: año + pregunta + explicación breve.
- Source drawer: evidencia para adultos/docentes, nunca bloquea el recorrido infantil.
- Choice: puerta de exploración.
- Landscape: representación abstracta del territorio.

## Responsive
Mobile es la referencia. Desktop amplía el espacio; no agrega complejidad.

## Regla de profundidad
La interfaz muestra una idea por vez. Los datos, fuentes, estados editoriales y relaciones históricas viven detrás.
