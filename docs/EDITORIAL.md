# Criterio histórico y editorial

Este proyecto no inventa la historia local para completar pantallas.

Cada contenido pasa por: fuente → investigación → verificación → adaptación → publicación.

Se diferencian hechos documentados, testimonios y memoria oral, interpretaciones de investigadores y contenido didáctico. Si existen versiones diferentes, se conserva la diferencia y se atribuye a cada fuente.
