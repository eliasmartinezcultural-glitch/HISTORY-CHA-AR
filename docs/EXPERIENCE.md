# Experiencia · V0.3

## Principio
El niño no recorre una base de datos. Recorre preguntas.

Cada contenido profundo se traduce en una experiencia breve:
- una pregunta;
- una pista;
- una observación;
- una relación;
- una pequeña conclusión.

## Capas
**Capa 1 · Descubrir:** lenguaje breve y visual.
**Capa 2 · Comprender:** explicación contextual.
**Capa 3 · Investigar:** fuente, documento y relación.
**Capa 4 · Docente:** material para profundizar.

## Regla de interacción
No usar interacción como decoración. Cada gesto debe revelar una relación histórica, una fuente o un cambio territorial.

## Regla de accesibilidad
Todo descubrimiento debe tener equivalente textual y funcionar con teclado.

## Regla editorial
Un testimonio oral puede enriquecer la experiencia, pero nunca se convierte automáticamente en hecho histórico. Debe identificarse como testimonio y conservar su procedencia.
