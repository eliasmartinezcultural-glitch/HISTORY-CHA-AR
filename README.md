# HISTORY-CHA-AR

## V0.2 · Núcleo de experiencia

Experiencia educativa interactiva para enseñar la historia de San Patricio del Chañar durante el ciclo primario.

### Regla mundial
**MUCHA PROFUNDIDAD DETRÁS → MÁXIMA SENCILLEZ DELANTE.**

Cada capa es un vagón del mismo tren:
1. Entrada inmediata.
2. Pregunta.
3. Elección sencilla.
4. Descubrimiento.
5. Evidencia/fuente.
6. Próxima conexión.
7. Nuevo descubrimiento.

### Públicos
Niñas y niños de primaria, docentes y familias. Celular, tablet, notebook y PC.

### Reglas de producto
- Primero funciona; después se embellece.
- Una acción principal por pantalla.
- Todo funciona con toque o clic.
- Nada esencial depende de hover.
- Texto corto delante; profundidad documental detrás.
- No inventar hechos históricos.
- Diferenciar hechos, fuentes, testimonios e interpretaciones.
- Conectar territorio, agua, personas, producción, instituciones y presente.
- Accesibilidad y responsive desde el comienzo.
- No sumar funciones decorativas que no aporten aprendizaje o uso.

### Núcleo V0.2
Inicio → caminos → descubrimiento → fuente → volver a explorar.

La información está separada del renderizado para permitir crecer sin convertir la interfaz en un laberinto.

### Próximas capas
